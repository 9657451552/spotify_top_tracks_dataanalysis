
# Spotify Top Tracks Data Analysis Using Python

## Project Overview

This project performs Data Analytics on the Top Spotify Tracks of 2018 dataset using Python.

The project analyzes Spotify audio features such as:
- Danceability
- Energy
- Loudness
- Acousticness
- Instrumentalness
- Liveness
- Valence
- Tempo
- Duration

## Dataset

Dataset: Top Spotify Tracks of 2018

Dataset file: top2018.csv

Dataset shape: 100 rows x 16 columns

Missing values: 0

## Objectives

- Understand the Spotify dataset.
- Check missing values and data quality.
- Perform descriptive statistics.
- Analyze top artists.
- Analyze energy and danceability.
- Analyze acousticness.
- Study correlations between audio features.
- Create visualizations.
- Generate meaningful insights.
